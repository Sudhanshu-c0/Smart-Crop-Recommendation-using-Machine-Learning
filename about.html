Problem statement

Agricultural challenges and data-driven crop selection

Agriculture plays a vital role in food security and rural development. However, selecting a suitable crop is difficult when soil and environmental conditions vary across regions and seasons.

Traditional choices often rely on experience and broad assumptions, which may overlook the combined effects of soil nutrients and climate. An unsuitable crop can lead to inefficient fertilizer use, reduced productivity, and declining soil fertility.

AGRI MITRA addresses this challenge with a data-driven decision-support platform that evaluates soil nutrients and climate factors to suggest appropriate crops and fertilizer requirements.

System boundaries

Project scope and limitations

✅ Within project scope

  • Analysis of seven soil and environmental parameters
  • Recommendation of optimal crop candidates
  • Fertilizer and nutrient balance guidance
  • Responsive standalone web frontend
  • Decision support for farmers and researchers

❌ Out of current scope

  • IoT-based real-time sensor monitoring
  • Automated irrigation systems
  • Plant disease and pest image detection
  • Actual crop yield forecasting
  • Live market price tracking

Integration roadmap

Future machine learning architecture

The current frontend is modularly decoupled from prediction logic. A future phase can replace the static handlers with asynchronous REST API calls to a trained Python or Flask backend.

1
Frontend parameter ingestion

Users enter soil nutrients and climate parameters in recommendation.html with instant validation.

2
Asynchronous REST dispatch

JavaScript constructs a JSON payload and sends a POST /api/predict request to the Flask server.

3
Feature scaling and ML inference

A Random Forest or XGBoost model evaluates the feature matrix and returns crop probability scores.

4
Fertilizer rule engine and response rendering

The backend appends fertilizer recommendations and returns structured JSON to the frontend.
